# USER_MANUAL (ringkas, Bahasa Indonesia)
## Masuk
Buka `/login`, masukkan email + kata sandi. Menu menyesuaikan peran Anda.

## Klien
`/clients` → Cari (otomatis) atau Klien Baru → isi jenis, nama, telepon, email, alamat,
NPWP bila ada → Simpan. Buka detail untuk melihat peringatan duplikat.

## Permohonan
`/requests` → pilih Klien + Layanan + judul → Buat → gerakkan status via dropdown
(DRAFT→SUBMITTED→IN_REVIEW→APPROVED→IN_PROGRESS→COMPLETED).

## Akta & Register
`/deeds` buat draf → revisi disimpan berversi → setujui (notaris) → terkunci.
`/repertorium`, `/protocols`, `/legalisasi` mencatat register resmi + biaya.

## Keuangan
`/finance` → Invoice Baru (PPN 11% otomatis) → catat pembayaran per invoice;
kelebihan bayar ditolak sistem. Pantau Piutang & Penerimaan bulan berjalan.

## Portal klien & Laporan
`/portal` untuk status permohonan Anda. `/reports` angka operasional real-time.
