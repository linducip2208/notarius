# COMPONENT CATALOG — kelas Tabler yang dipakai (bukan komponen baru)

| Kebutuhan | Kelas Tabler | Lokasi |
|---|---|---|
| Shell | `page`, `navbar-vertical[data-bs-theme=dark]`, `page-wrapper` | partials |
| Topbar | `header.navbar`, `input-icon`, `avatar`, `dropdown-menu-end` | partials |
| Navigasi | `navbar-nav/nav-link`, `nav-tabs card-header-tabs` | partials, client_detail |
| Kartu/stat | `card`, `card-header/body/footer`, `subheader`, `display-6/h1` | semua |
| Tabel | `table card-table table-vcenter`, `table-responsive` | list, repertorium |
| Badge/status | `badge bg-{blue,yellow,green,red,azure}-lt`, `rounded-pill` | semua |
| Tombol | `btn`, `btn-primary/warning/success/outline-*/ghost-secondary`, `btn-sm` | semua |
| Form | `form-control/select`, `form-check`, `input-group` | form |
| Pagination | `pagination/page-item/page-link` | clients |
| Dropdown/aksi | `dropdown`, `data-bs-toggle` | topbar, quick actions |
| Tab | `nav-tabs` + `tab-content/tab-pane` + `data-bs-toggle=tab` | client_detail |
| List/aktivitas | `list-group/list-group-flush`, `ribbon`, `alert` | dashboard, roles |
| Detail | `dl.row/dt/dd`, `breadcrumb`, `avatar-lg`, `card-img-top` | detail |
| Utilitas | `d-flex/gap-*/sticky-top/border/breadcrumb/divider` | umum |

DILARANG menambah kelas kustom baru. Inline `style` hanya untuk dimensi gambar/grafik.
