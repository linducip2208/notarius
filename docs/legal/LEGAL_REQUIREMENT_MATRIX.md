# Matriks Persyaratan Hukum (Legal Requirement Matrix)

> Status: NEEDS_LEGAL_REVIEW — belum ditinjau notaris penasihat. Daftar umum, bukan nasihat hukum.

## 1. Persyaratan Dokumen per Layanan Utama

| Layanan | Dokumen Umum yang Diminta | Status |
|---|---|---|
| Pendirian PT | KTP/NPWP pendiri, nama PT, modal, susunan pengurus, domisili | NEEDS_LEGAL_REVIEW |
| Perubahan PT / RUPS | Akta terakhir, undangan & daftar hadir RUPS, keputusan rapat | NEEDS_LEGAL_REVIEW |
| Perjanjian / PPJB | Identitas para pihak, objek perjanjian, dokumen pendukung objek | NEEDS_LEGAL_REVIEW |

| Legalisasi / Waarmerking | Dokumen asli, identitas penghadap | NEEDS_LEGAL_REVIEW |
| Keterangan waris | Kematian, KK, KTP ahli waris, dokumen pendukung hubungan | NEEDS_LEGAL_REVIEW |

## 2. Pemeriksaan Wajib Sebelum Akta

1. Identitas & kewenangan penghadap (KTP, kuasa bila mewakili).
2. Kapasitas bertindak (dewasa/cakap menurut peraturan umum).
3. Kelengkapan dokumen pendukung sesuai jenis layanan.
4. Perlindungan data pribadi sesuai UU PDP 27/2022 (persetujuan & akses terbatas).
5. Pengecekan konflik kepentingan / rangkap jabatan bila relevan.

## 4. Pengecualian Umum

- Dokumen tidak lengkap: akta tidak dapat dibuat sampai dilengkapi.
- Indikasi pemalsuan/penekanan: tolak atau tunda, catat di log.
- Sengketa pengadilan berjalan atas objek: arahkan ke penetapan pengadilan.
- Data pribadi tanpa persetujuan: batasi pemrosesan sesuai UU PDP 27/2022.
- Layanan PPAT/BPN: di luar aplikasi ini (lihat Service Authority Matrix).

> Tanpa nomor pasal/ayat spesifik. Konfirmasi ke notaris penasihat sebelum operasional.
