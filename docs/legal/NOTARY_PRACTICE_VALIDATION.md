# Validasi Praktik Notaris (Notary Practice Validation)

> Status: NEEDS_LEGAL_REVIEW — klasifikasi awal tim, belum ditinjau notaris penasihat.

## Prinsip Pembedaan

1. **Kewajiban peraturan** — diwajibkan UU/peraturan generik, tidak boleh diubah kantor.
2. **SOP kantor** — kebijakan internal kantor untuk konsistensi, boleh diperketat.
3. **Praktik umum** — kebiasaan lazim profesi, tidak mengikat seperti UU.
4. **Konfigurasi aplikasi** — pilihan teknis di sistem, bukan hukum.

## 1. Kewajiban Peraturan (contoh)

- Pembuatan akta autentik & minuta sesuai UUJN 2/2014.
- Kewajiban arsip 25 tahun menurut UUJN.
- Prinsip UU PT 40/2007 untuk akta korporat.
- Batas praktik PPAT merujuk PP 24/2016 (tidak dijalankan di aplikasi ini).
- Pelindungan data pribadi menurut UU PDP 27/2022.

## 2. SOP Kantor (contoh di aplikasi)

- Checklist dokumen wajib sebelum penjadwalan akta.
- Verifikasi ganda identitas penghadap oleh staf + notaris.
- Alur persetujuan draf akta sebelum penandatanganan.
- Penomoran register & penyimpanan minuta terpusat.

## 3. Praktik Umum (contoh)

- Template bahasa akta baku yang lazim dipakai.
- Urutan pembacaan akta di hadapan penghadap & saksi.
- Format buku register tambahan untuk kerapian administrasi.

## 4. Konfigurasi Aplikasi (BUKAN hukum)

- Nama status order, warna label, tampilan dashboard.
- Durasi SLA pengingat internal, format nomor antrean.
- Template notifikasi WhatsApp/email.
- Hak akses peran (admin/staff) di CMS.

## Aturan Pakai

- Konfigurasi tidak boleh disajikan sebagai kewajiban hukum.
- Perubahan SOP kantor dicatat di Regulatory Review Log.
- Setiap klaim "wajib menurut UU" harus NEEDS_LEGAL_REVIEW hingga dikonfirmasi penasihat.
